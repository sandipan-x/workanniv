# WorkAnniv

Calculate years of service from any start date, countdown to 5/10/15/20-year milestones, and track team anniversaries on a shared board. Free tool.

## Features
- Next milestone (5/10/15/20-year) countdown with celebration ideas
- Team anniversary board for upcoming work anniversaries
- Tenure leaderboard ranked by years of service
